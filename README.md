# Chromium Bookmark Duplicate Cleaner

Chromium系ブラウザ（Chrome, Vivaldi等）のブックマークから重複を検出し、スッキリ整理するための拡張機能です。

## 特徴
- **重複の自動検出**: 大量のブックマークから重複しているものをグループごとに一覧表示します。
- **YouTubeのURL正規化対応**: URLにタイムスタンプ（`t=○○`）やパラメータがついていることで見落とされていた重複も、動画IDを基準にしてしっかり検出します。
- **安心のバックアップ機能**: 整理・削除を行う前に、現在の全ブックマークをJSON形式で一括バックアップできます。
- **柔軟な削除・整理**: 
  - チェックを入れた項目だけを手動で削除
  - 各グループで「最新1件だけ残す」などの一括選択ヘルパー
  - 一番古いものを残して他をすべて消す一括自動整理

## 📥 ダウンロード・導入方法

1. 以下のリンクから最新のZIPファイルをダウンロードします。
   👉 [**bookmark-cleaner-v1.1.zip をダウンロードする**](https://github.com/MustangTIS/Chromium-bookmark-duplicate-cleaner/releases/download/v1.1/bookmark-cleaner-v1.1.zip)

2. ダウンロードしたZIPファイルを**解凍（展開）**します。
   > ⚠️ **注意**: ブラウザがこのフォルダを直接参照して動作するため、**解凍したフォルダは途中で移動・削除しない固定の場所（ドキュメントフォルダ内など）に置いてください。**

3. ブラウザのアドレスバーに Chromeの場合は `chrome://extensions/` を入力して拡張機能管理ページを開きます。※お使いのブラウザによってはアドレスが変わります。（例：Vivaldiの場合は `vivaldi://extensions/` 、 Edgeの場合は `edge://extensions/` ）
4. 画面右上にある **「デベロッパーモード」をON** にします。
5. 画面左上に現れる **「パッケージ化されていない拡張機能を読み込む」** をクリックし、先ほど解凍したフォルダを選択します。

6. ツールバーに追加された拡張機能のアイコンをワンクリックすると、専用の管理タブが開きます。

---

## ⚠️ ご利用上の注意
大量のブックマークを削除・変更する機能が含まれています。**必ず作業前に「現在の全ブックマークをバックアップ」ボタンからバックアップファイルを取得してからご利用ください。**
